# inverted_pendulum

This project is one of the projects I undertook during my third year (Part IIA) studying the Engineering Tripos at the University of Cambridge. This project focusses on applying predictive control methods to invert and stabilise a freely-rotating pendulum. The results of the work are found in the provided notebooks, extensively edited from the originally provided templates, while the code is distributed across a range of python files. The resultat report is not included here.
